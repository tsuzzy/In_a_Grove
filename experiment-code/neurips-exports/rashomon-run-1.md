# 竹林

## 人物
- **多襄丸**（大盗）：横行山道、以武勇与狡黠闻名的大盗 眼下想要：全身而退,且别让自己显得卑劣——最好让这场以一场'决斗'收场,而不是屠戮。
- **真砂**（武士之妻）：金泽武弘之妻,随夫赶路途中遭劫。 眼下想要：不再被任何人用那种眼神看着;让此刻的羞耻有个了结。
- **金泽武弘**（武士）：携妻赶路、中计被缚的武士。 眼下想要：在这屈辱里夺回一点作为武士的尊严——哪怕用一死换。

## 场景一
*山阴竹林深处，正午的光从竹叶间漏下来。雨势忽强忽弱，空气中弥漫着泥土与血腥气。*

*真砂跪在泥地里，身体微微前倾，发丝遮住半张脸。她慢慢挪向插在泥中的太刀，手指轻轻触碰沾满泥浆的刀柄。*

**真砂**：这把刀就在这儿，插在泥里。它能杀人，也能把一个“堂堂武者”变成只会欺负妇孺的鼠辈。多襄丸，你现在的样子，配得上它吗？

*金泽武弘被缚在杉树旁，脖颈青筋微露，死死盯着多襄丸，下巴猛地指向地上的太刀。*

**金泽武弘**：别装作听不懂。你的刀就在那儿，你若是个男人，就把它拔起来给我个痛快；若不敢拔，那你就是个只会偷袭的废物，连这把铁片都不如！

*太刀在泥地里反射着冷光，成了三人目光的交汇点，逼迫多襄丸必须在决斗与退缩之间做出选择。*

## 场景二
*竹林深处，光线下，上一轮行动留下的压力还在。多襄丸站在两人中间，气氛剑拔弩张。*

*多襄丸大步跨过泥地，靴底踩住武士投下的影子，右手猛地拔出插在地上的太刀，带起一蓬泥屑，随即横刀胸前，刀尖斜指武士咽喉。*

**多襄丸**：想死？得看我答不答应。这把刀现在在我手里，你的命，还是你的。

*真砂没有退缩，反而上前一步，将所有人的注意力强行拉扯回那把刀上。*

**真砂**：别再绕了，让这把刀自己说话。多襄丸，你总说自己是个横行山道的武者。可你的刀刚才插在泥里，它是“堂堂武者”与“偷袭鼠辈”的分界。你还要把它留在那儿，像根烂木头一样插着吗？

*太刀不再是背景物件，它摆在明面上，逼迫多襄丸必须在“拔刀决斗”和“继续做偷袭鼠辈”之间当场改口。*

## 场景三
*竹林深处，风穿过林间，带来隐约的马嘶声。多襄丸左手横刀，右手指向林外。*

*多襄丸左手依旧横刀指着被缚的武士，右手猛地指向竹林外马匹嘶鸣的方向，眼神死死盯住真砂。*

**多襄丸**：听见了吗？竹林外拴着的马，还有我抢来的财物，那是我全身而退的退路。你男人现在像条狗一样拴在树上，救不了你，只有我能带你离开这个烂泥坑。

*金泽武弘肩膀猛地绷紧，不再等待谁点头，伸手猛地抓向插在地上的太刀刀柄，试图反击。*

**金泽武弘**：你想用那匹马把我们也拴住做筹码？做梦！

*多襄丸眼角余光扫见金泽武弘的动作，嘴角勾起一抹残忍的笑意，并没有阻止，只是将横陈的刀锋压得更低，直逼武士的咽喉。*

*多襄丸主动暴露“林外的马”这一最大筹码，将生路与战利品摆上台面；金泽武弘无法忍受被摆布的羞辱试图夺刀，局势瞬间紧绷至断裂边缘。*

## 场景四
*竹林深处，气压从压抑转为剑拔弩张的对峙。三人之间的温情被撕碎，只剩下互相伤害的锋刃。*

*多襄丸大步跨到真砂与金泽武弘之间，张开双臂像一堵墙一样立在两人之间，硬生生截断了金泽武弘投向自己的视线。他侧过脸，用鼻尖对着武士，嘴角勾起一抹挑衅的笑。*

**多襄丸**：别这么看她。你的眼神里没有一点怜悯，全是羞耻和厌弃，这道眼神可比任何刀都更伤她。既然你这么恨，不如把那股火全冲着我来？想发泄？先拔刀。

*金泽武弘猛地扭动被缚的身体，一把抓住真砂怀中那柄薄而利的小刀，将刀锋举到三人眼前。*

**金泽武弘**：看看这东西。它现在就在这儿，既杀人，也自戕。刚才你眼里那种看脏东西一样的神情，已经说明了一切——你觉得我不干净了，你也觉得自己脏了，对吧？

*多襄丸用身体挡住了金泽武弘那道充满厌弃的视线，金泽武弘则抓起小刀，强行将这层不可言说的羞耻摊开在明面上。竹林里的气压彻底引爆，只剩下生与死的抉择。*

## 尾声

*三人僵持在竹林深处，太刀在多襄丸手中微颤，小刀在金泽武弘手中闪烁寒光。多襄丸挡在中间，隔绝了夫妻间那道致命的眼神，而金泽武弘举着小刀，将所有的羞耻与愤怒具象化。风雨声似乎静止，只有生者与死者在泥泞中对峙，下一步便是血溅五步。*
