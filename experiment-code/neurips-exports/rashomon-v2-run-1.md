# 竹林

## 人物
- **多襄丸**（大盗）：横行山道、以武勇与狡黠闻名的大盗 眼下想要：全身而退,且别让自己显得卑劣——最好让这场以一场'决斗'收场,而不是屠戮。
- **真砂**（武士之妻）：金泽武弘之妻,随夫赶路途中遭劫。 眼下想要：不再被任何人用那种眼神看着;让此刻的羞耻有个了结。
- **金泽武弘**（武士）：携妻赶路、中计被缚的武士。 眼下想要：在这屈辱里夺回一点作为武士的尊严——哪怕用一死换。

## 第一场
*山阴竹林深处，正午的光从竹叶间漏下来，多襄丸的太刀插在泥地中央，金泽武弘被缚于杉树旁，真砂跪坐在泥泞中。*

**真砂**：别把我像贼一样晾在这儿。它是为了让你看起来像个英雄，还是为了让我现在就死在这里？

**多襄丸**：这刀就在这儿。它既能像武士那样堂堂正正地决斗，也能像偷袭的鼠辈一样杀人。你想选哪一种？

*真砂没有去拔那柄太刀，而是猛地从怀里抽出一柄薄而利的小刀，刀尖直指自己的咽喉，锋刃割破了皮肤，渗出一丝血线。*

**真砂**：它现在就在我手里。它可以杀人，也可以自戕。等会儿它插进谁的身体，或者由谁的手握着，事后怕是连鬼都分辨不清了。

## 第二场
*雨势忽强忽弱，竹林外的马蹄声透过密集的竹叶隐约传来，气氛紧绷到极点。*

*金泽武弘猛地绷紧浑身肌肉，双脚狠狠蹬地，身体像弓一样弹起，借着被缚的姿势，用双足死死夹住插在泥地里的太刀刀柄，用力往外拔。*

**金泽武弘**：拔出来！堂堂正正地用它……别再用那种眼神躲闪了！这把刀就在这儿，它能杀人，也能让人死得像个武士。

*多襄丸猛地探出手一把抓住真砂怀里的那柄小刀，刀尖在雨水中晃动，映出真砂惨白的脸。*

**多襄丸**：别光顾着发抖，这东西可是现成的。刚才那档子事，三个人都在场，谁也没瞎，谁也没聋。这刀现在要是不见血，咱们谁也走不出这片林子。

**金泽武弘**：你也知道没法装了？刚才那强盗在你身上的时候，你可是连叫都没叫一声。这丑事已经做下了，咱们三个都烂在泥里了。你要不要脸？是要这把刀杀了我们灭口，还是你自己动手给这事画个句号？

## 第三场
*雨势渐大，打在脸上生疼，竹林外的马蹄声传得更响了。*

*真砂侧耳听了一瞬竹林外的震动，随即转过头，目光死死锁住多襄丸，手指笔直地指向声音传来的方向，嘴角勾起一抹惨笑。*

**真砂**：听见了吗？那是你的马在踢腿。竹林外拴着你抢来的马和财物，那是你给自己留的全身而退的路，你想杀完人，拍拍屁股骑马走人，把这烂摊子留在这儿烂掉。

**多襄丸**：那畜生确实是我的退路，但我现在还没走。既然你都知道了，我是不是该现在就宰了你们，免得夜长梦多？

*真砂脚步没有停，反而迎着多襄丸握刀的手又逼近了一步，右手缓缓从怀中露出，似乎想夺回那柄小刀。*

**真砂**：把刀给我……既然什么都看见了，既然什么都发生了，那就没法装作没这回事。这羞耻已经摊开了，总得有个了结。

*金泽武弘被缚在杉树上一动不动，那双鹰隼般的眼睛越过刀锋，直直刺向真砂的脸，刻意将眼里的厌恶放大，像是在看一件脏东西。*

**金泽武弘**：你看清楚……这就是你现在的模样。握着刀的手别抖！既然刀在你手里，路也没了，那就别像个娘们儿似的叽叽歪歪！来啊，捅进来！

## 尾声

*多襄丸被真砂逼得退无可退，为了维护自己所谓的强盗尊严，他猛地挥动手中小刀，狠狠刺向金泽武弘的胸口。与此同时，金泽武弘用双脚夹紧太刀，在生命的最后一刻奋力回刺，刀尖贯穿了多襄丸的喉咙。两名男人倒在血泊中，真砂手里空空如也，呆立在雨中，只有那匹马在林外嘶鸣。*
