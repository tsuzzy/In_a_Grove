# 竹林

## 人物
- **多襄丸**（大盗）：横行山道、以武勇与狡黠闻名的大盗 眼下想要：全身而退,且别让自己显得卑劣——最好让这场以一场'决斗'收场,而不是屠戮。
- **真砂**（武士之妻）：金泽武弘之妻,随夫赶路途中遭劫。 眼下想要：不再被任何人用那种眼神看着;让此刻的羞耻有个了结。
- **金泽武弘**（武士）：携妻赶路、中计被缚的武士。 眼下想要：在这屈辱里夺回一点作为武士的尊严——哪怕用一死换。

## 第一场：毁刀
*山阴竹林深处，正午的光从竹叶间漏下来。多襄丸的太刀插在两人之间的泥地里，金泽武弘被缚于杉树，真砂衣衫不整地立在一旁。*

*多襄丸大步跨到插在泥地里的太刀旁，右手握住刀柄，并未拔出，只是用皮靴重重踏住刀锷附近的泥土，试探刀身的稳固。*

**真砂**：别演了。这把刀插在这儿，不是为了决斗，是为了遮羞。

*真砂径直走向太刀，猛地拔出，反手将刀重重掷向竹林深处的灌木丛，发出一声闷响。*

*金泽武弘被缚在杉树上，身体猛地一挣，绳索勒进皮肉，他死死盯着太刀消失的方向，喉结滚动。*

*真砂掷出太刀，毁掉了多襄丸预设的“决斗场”，迫使强盗无法再用“堂堂正正”的武士规则来掩饰刚才的暴行。*

## 第二场：对质
*山阴竹林深处，光线依旧，但气氛因太刀的消失而变得更加紧绷。*

**多襄丸**：武士，事情已经做下了，这满地的狼藉你也瞧得真切。咱们谁也装作没发生，现在就剩这三条命，你打算怎么算？

*真砂猛地向前跨一步，把怀里的半截刀鞘亮出来，直指被缚的丈夫。*

**真砂**：你也看见了吧？刚才就在这儿，三个人都在场，谁也没瞎。既然你什么都看见了，就别再用那种眼神看我。

*多襄丸侧过身，不动声色地用身体挡住了两人刚才倒卧的位置，切断了金泽武弘继续看向那里的视线。*

*多襄丸封住现场，真砂以实情相逼，三人都无法再假装凌辱未曾发生，冲突从物理层面转向心理层面。*

## 第三场：逼视
*山阴竹林深处，雨势忽强忽弱，泥泞的地上插着多襄丸的太刀，寒光在竹叶漏下的光影里闪动。*

*金泽武弘猛将被缚的双腕前送，插在地上的太刀被这股蛮力震得嗡鸣，刀身出鞘半寸，森寒的刃尖借着雨势直逼真砂的眼睛。*

**金泽武弘**：多襄丸的太刀不杀无名之辈。真砂，你要么解开这绳子让我像个武士一样去死，要么就用你怀里的东西动手，别让这把刀在泥地里笑话我们都是苟且偷生的老鼠。

**多襄丸**：金泽武弘，你这双手被绳子捆着，就算握着它，也分不清自己是武者还是待宰的猪。

*金泽武弘手腕猛转，太刀带着风声扫过地面，将真砂那柄小刀击飞进远处的黑泥中，溅起一片污浊的水花。他随即刀尖微抬，锁住多襄丸。*

**金泽武弘**：收起你那点念头。这把刀若再出现在手里，不管是刺进谁的喉咙，咱们三个这辈子都别想再洗干净。

*金泽武弘用太刀的寒光逼迫真砂直面选择，随后击飞小刀，切断了真砂用物理手段结束局面的可能。*

## 第四场：鄙夷
*山阴竹林深处，正午的光从竹叶间漏下来，空气因这赤裸的指控而凝固。*

*多襄丸伸出两指，从真砂的视线方向虚虚指向金泽武弘的双眼，强迫她直视那道目光。*

**多襄丸**：别看泥里的刀了，真砂。看看你男人的眼。那里面没有半点怜惜，只有嫌恶——就像看着一坨甩不掉的烂泥。

*真砂猛地转头，死死盯住金泽武弘的双眼，手指颤抖地指向他的瞳孔。*

**真砂**：你也看见了。那眼里没有怜悯，只有想把我当脏东西抹掉的鄙夷。你要我死，好让你这身武士皮囊能干干净净地挂回墙上去！

*多襄丸揭露金泽武弘眼中的鄙夷，将夫妻间的裂痕从隐忍的屈辱摆到了明面上，逼迫三人直面这道无法撤回的羞辱目光。*

## 尾声

*三人僵立在竹林中，小刀沉入黑泥，太刀横在身前，而那道鄙夷的目光比任何利刃都更深地扎进了真砂的心里。活下去的路断了，体面的路也没了，只剩下赤裸的仇恨与绝望在雨中发酵。*
