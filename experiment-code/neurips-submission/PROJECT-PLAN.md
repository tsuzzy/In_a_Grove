## 质量底线（每条入选命运必须全过)

1. **真 GLM**:finalModel = `zai-glm-4.7+script-scenes`,GLM 回合占多数(非本地模板)。
2. **死亡落定**:结尾是不可逆的终局事件(谁死/怎么死/或明确逃离),不是"僵持/一触即发"。
3. **无分析腔总结句**:每场收在动作/对白。
4. **无年代穿帮**:无现代道具/词(电/枪/公司/手机…)。
5. **互不相同**:N 条命运的死法/走向要有真分叉(理想:覆盖强盗杀/真砂杀/武士自尽 + 芥川没写过的)。

→ 用 `node outputs/neurips-submission/rashomon-quality-gate.mjs` 自动体检(每次跑完就跑它)。
