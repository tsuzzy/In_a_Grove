# 竹林

## 人物
- **多襄丸**（大盗）：横行山道、以武勇与狡黠闻名的大盗 眼下想要：全身而退,且别让自己显得卑劣——最好让这场以一场'决斗'收场,而不是屠戮。
- **真砂**（武士之妻）：金泽武弘之妻,随夫赶路途中遭劫。 眼下想要：不再被任何人用那种眼神看着;让此刻的羞耻有个了结。
- **金泽武弘**（武士）：携妻赶路、中计被缚的武士。 眼下想要：在这屈辱里夺回一点作为武士的尊严——哪怕用一死换。

## 第一场：夺刀
*山阴竹林深处，正午的光从竹叶间漏下来。一柄太刀插在泥地里，在三人之间划出一道生与死的界线。*

*真砂发丝散乱，眼神狠厉地盯着插在地上的太刀。她不顾衣衫不整，猛扑过去双手死死握住刀柄，试图拔出这柄能决斗也能杀人的利刃，身体因用力而剧烈战栗。*

*多襄丸跨前一步，左手如铁钳般扣住真砂的手腕用力一拧，迫使她惨叫着松开刀柄。他右手顺势握住插在地上的太刀，猛地拔出带起一片泥土，将这界定“堂堂武者”与“偷袭鼠辈”的兵器横在身前。*

**多襄丸**：这东西沉重，不是妇人的手能拿的。这可是只有武士才配用的凶器。

*多襄丸手腕一转，刀尖挑向被缚在树上的金泽武弘，冷眼看着那对夫妻。*

**真砂**：你若真当自己是条好汉，就别摆这架势！杀人还是决斗，你今天总得选一个说清楚！

## 第二场：藏锋
*竹林外围，马蹄声躁动。光线依旧惨白，照着三人紧绷的脸。*

*多襄丸大步走向林外，一把抓住拴着的马的缰绳，用力将其拽得嘶鸣一声，转身将缰绳在手中甩得啪啪作响，指着真砂。*

**多襄丸**：别争了！听外面——我的马就在那。只要我不松缰绳，谁也走不出这片林子。

*真砂猛地转向多襄丸，挺直散乱的衣襟，死死盯着他手中的缰绳，不再看那马一眼。她右手悄然探入怀中，紧紧攥住那柄薄而利的小刀。*

**真砂**：拿畜生做墙？这就是大盗的威风？你要走就走，要杀就杀，别拿那畜生来压我！

*真砂的指节因用力而发白，她感到怀中的小刀冰冷刺骨。这刀可以杀人，也可以自戕，此刻它是她唯一的筹码。*

## 第三场：鄙夷
*竹林深处，死寂。只有被缚于杉树上的武士发出粗重的喘息。*

*多襄丸冷笑着退开一步，目光在夫妻二人之间游移，最后落在武士脸上，似乎在欣赏某种更残酷的戏码。*

**多襄丸**：我不杀你们，我要你们自己看清楚。看看你们现在的样子，多体面。

*真砂猛地把头转向被缚的丈夫，直视他的眼睛，目光如刀，试图从那双眼睛里读出哪怕一丝动摇或恐惧。*

**真砂**：你刚才不是在看吗？现在把头抬起来，接着看！

*金泽武弘猛地抬起头，双眼圆睁，没有避开真砂的视线，而是狠狠地瞪回去。眼中刻意流露出毫不掩饰的羞耻与厌弃，像是在看一件脏东西，死死锁定她的脸。*

**金泽武弘**：看清楚了吗？这就是你要的眼神！

## 第四场：终局
*竹林深处，风声骤停。光斑静止，仿佛连时间都凝固在这一刻。*

*真砂在丈夫那如冰锥般的目光下浑身一颤，那是比死亡更令她胆寒的羞耻。她发出一声凄厉的嘶吼，猛地抽出怀中的小刀。*

**真砂**：别那样看我！闭嘴！

*她没有扑向多襄丸，也没有刺向丈夫，而是转身将刀尖对准了自己的喉咙。*

*多襄丸脸色一变，扔下缰绳欲冲上前阻拦，却被地上的树根绊了一步。*

**多襄丸**：疯了！

*就在真砂即将倒下的瞬间，被缚在树上的金泽武弘猛地挣断了因雨水浸泡而松动的绳结，发出野兽般的咆哮，合身扑向真砂。*

*鲜血飞溅。真砂手中的小刀在混乱中刺入了金泽武弘的胸口，而武士双手死死掐住了妻子的咽喉。*

*两人纠缠着倒在地上，不动了。那柄染血的小刀插在武士的心口，真砂倒在血泊中，双眼圆睁，终于不再被任何人注视。*

## 尾声

*金泽武弘挣断绳索扑向真砂，撞上了她自杀用的匕首，匕首刺入武士心脏；真砂则被武士死死掐断咽喉。二人双双惨死。多襄丸看着两具尸体，夺回太刀，在这场没有赢家的对峙中独自活了下来。*
